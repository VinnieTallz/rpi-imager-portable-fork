Why PiFlash Portable?

Built for Portability & Clean Systems

🚀

True Zero-Install

Extract and run. No Windows installer, no elevated system file installations, and no leftovers in your Windows registry when you're done.

📁

Local Storage Sandbox

All downloaded OS images, temporary caches, and user settings stay strictly contained within a local ./data folder alongside the executable.

🔌

On-Demand RPIBoot

Flashing Compute Modules or unbricking RP2040/RP2350 microcontrollers? The WinUSB driver installs automatically on the fly via pnputil only when needed.

🛡️

Privacy by Default

Telemetry and usage reporting are turned off completely by default. Your imaging activity remains entirely local to your device.

🥊

Champion Edition Styling

Revamped visual palette inspired by classic Capcom arcade aesthetics (Hadouken Royal Blue, Electric Cyan, and Arcade Gold) with distinct fork branding.

⚡

Lightweight & Self-Contained

Packaged with all necessary Qt and MinGW runtime binaries included. Plug your USB drive into any Windows PC and start flashing immediately.

Getting Started

How to Run PiFlash Portable

1

Download the ZIP

Download PiFlash-Portable-win64.zip from our GitHub releases. No setup installer needed.

2

Extract Anywhere

Extract the folder to your desktop, downloads, or directly onto a portable USB flash drive.

3

Launch & Flash

Double-click rpi-imager.exe. Choose your target hardware, select your OS, pick your SD card, and hit write!

Security & Integrity

Windows SmartScreen / Defender Note

Why does Windows say "Unknown Publisher" or "Windows protected your PC"?

Because PiFlash Portable is a newly released, community-built open-source binary compiled on GitHub Actions, it has not yet accumulated cryptographic reputation in Microsoft's SmartScreen database. The app is 100% open-source and clean.

To launch without interruption:

1. When the blue SmartScreen prompt appears, click "More info".

2. Click "Run anyway".

Alternatively, you can unblock the downloaded ZIP using PowerShell before extracting:

Unblock-File -Path .\PiFlash-Portable-win64.zip
